### Week 1 Objectives:

- Get acquainted with the FCAJ (First Cloud AI Journey) community, its members, and the internship environment.
- Learn about the internship orientation and understand the objectives of the graduation thesis project: **Research and Implementation of Infrastructure Security on AWS**.
- Understand fundamental cloud computing concepts and the role of AWS in deploying and securing cloud infrastructure.
- Become familiar with the AWS Management Console, AWS account management, and basic resource management.
- Explore the AWS services relevant to the project, including **Amazon VPC, Amazon EC2, AWS IAM, Amazon RDS, Application Load Balancer (ALB), AWS WAF, AWS CloudTrail, Amazon CloudWatch, AWS Config, and AWS Systems Manager (SSM)**.
- Understand the importance of network isolation, access control, traffic filtering, logging, and security monitoring in AWS environments.

### Week 1 Results:

- Became familiar with the FCAJ community and understood the internship orientation.
- Gained fundamental knowledge of cloud computing and the AWS cloud platform.
- Successfully created an AWS account for learning and practical exercises.
- Became familiar with the AWS Management Console, Regions, and Availability Zones.
- Acquired basic knowledge of Amazon VPC, including public and private subnets, Internet Gateway, NAT Gateway, and route tables.
- Understood the roles of important AWS security and infrastructure services:
  - **Amazon VPC:** Provides an isolated networking environment for AWS resources.
  - **Amazon EC2:** Provides virtual servers for deploying and running workloads.
  - **AWS IAM:** Manages users, roles, and permissions to control access to AWS resources.
  - **Amazon RDS:** Provides managed relational database services.
  - **Application Load Balancer (ALB):** Distributes incoming application traffic across targets.
  - **AWS WAF:** Helps protect web applications against common web exploits.
  - **AWS CloudTrail:** Records account activity and API events for auditing.
  - **Amazon CloudWatch:** Collects monitoring data and provides visibility into AWS resources.
  - **AWS Config:** Evaluates and records resource configurations to support compliance monitoring.
  - **AWS Systems Manager (SSM):** Supports secure management and access to EC2 instances.
- Recognized the importance of network security, access control, traffic filtering, logging, and monitoring.
- Established the foundational knowledge required to design and implement a secure AWS infrastructure in the following weeks.
