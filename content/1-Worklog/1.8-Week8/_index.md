### Week 8 Objectives:

- Learn about AWS monitoring and logging services, including Amazon CloudWatch and AWS CloudTrail.
- Understand how CloudWatch collects and displays monitoring data from AWS resources.
- Learn how CloudTrail records user activities and API calls within an AWS account.
- Review AWS Config and understand how it evaluates resource configurations against security rules.
- Prepare monitoring and logging data for security analysis and evaluation.

- Understood the roles of Amazon CloudWatch and AWS CloudTrail in monitoring and recording activities within AWS infrastructure.
