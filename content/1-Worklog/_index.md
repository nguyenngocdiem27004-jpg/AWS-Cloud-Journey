**On this page**, you will find an overview of my worklog during the First Cloud AI Journey (FCAJ) internship program.

The worklog documents the activities, knowledge, and practical experience gained throughout the internship. It covers a period of 10 weeks, focusing on AWS cloud fundamentals, infrastructure deployment, and security implementation.

During these weeks, I studied AWS core services, designed and deployed an AWS network architecture, configured compute and database resources, and implemented security and monitoring services. I also performed basic connectivity and security tests to evaluate the deployed infrastructure.

The main activities completed during the internship are summarized below:

**Week 1:** [Introduction to AWS Cloud and Core AWS Services](1.1-week1/)

**Week 2:** [AWS Infrastructure Security Architecture Design and IP Address Planning](1.2-week2/)

**Week 3:** [Deploying Amazon VPC, Subnets, Internet Gateway, and Route Tables](1.3-week3/)

**Week 4:** [Deploying Amazon EC2 and Configuring Secure Access](1.4-week4/)

**Week 5:** [Configuring NAT Gateway and Private Network Routing](1.5-week5/)

**Week 6:** [Deploying Amazon RDS and Configuring Database Connectivity](1.6-week6/)

**Week 7:** [Deploying a Web Server on Amazon EC2 and Configuring Application Load Balancer](1.7-week7/)

**Week 8:** [Monitoring and Logging with Amazon CloudWatch, AWS CloudTrail, and AWS Config](1.8-week8/)

**Week 9:** [Configuring AWS WAF to Protect Web Applications](1.9-week9/)

**Week 10:** [Testing the AWS Infrastructure Security System and Optimizing Costs](1.10-week10/)
